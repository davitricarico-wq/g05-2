# Firmware dos protótipos físicos

Os códigos integrados estão organizados por função.

- [prototipo-contagem](../prototipo-contagem/) contém o contador Arduino Uno da Sprint 1, cujos casos CT01–CT10 foram documentados anteriormente.
- [prototipo-monitoramento](../prototipo-monitoramento/) contém o modelo 2 com ESP32 e RC522. CT16–CT23 documentam a simulação de uma versão anterior; CT24–CT28 são roteiros da versão atual, ainda sem execução.
- [prototipo-totem](../prototipo-totem/) contém o modelo 3 de confirmação offline, com CT29–CT32 planejados e não executados.

Este diretório preserva a referência documental do planejamento anterior CT11–CT15. O [registro consolidado de testes](../../../document/documentacao.md#testes-prototipos) relaciona cada modelo à versão do firmware, às evidências e às pendências. Nenhum CT físico da versão atual foi executado.
