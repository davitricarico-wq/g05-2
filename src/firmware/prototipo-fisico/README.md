# Firmware dos protótipos físicos

Os códigos integrados estão organizados por função.

- [prototipo-contagem](../prototipo-contagem/) contém o contador Arduino Uno da Sprint 1, cujos casos CT01–CT10 foram documentados anteriormente.
- [prototipo-monitoramento](../prototipo-monitoramento/) contém o modelo 2 com ESP32 e RC522, associado à simulação CT16–CT23.
- [prototipo-totem](../prototipo-totem/) contém o modelo 3 de confirmação offline, com testes específicos previstos para a Sprint 3.

Este diretório preserva a referência documental do planejamento anterior CT11–CT15. O [registro consolidado de testes](../../../document/documentacao.md#testes-prototipos) relaciona cada modelo à versão do firmware, às evidências e às pendências.
